# Separate products and migration

Anchor Task Assurance keeps the evidence gate and research workflow. ActionGate is a separate repository and import namespace, `actiongate`, so both can be installed together.

The Gemini standalone governor is not a drop-in dependency. The original accepted recomputed receipt checksums; its revision still allowed function defaults to escape partial scope binding. The broker now expands defaults, checks policy on the full action, stores an immutable proposal, and consumes a scoped ticket once with expiry and breaker revocation. Host-clock review sessions replace self-reported durations.

Actual provider IDs, credentials, semantic verification and identity authentication remain host responsibilities. Demos are synthetic and no percentage savings or model-accuracy claims are made.

## Current package interfaces

Anchor installs as `anchor-task-assurance`, imports as `anchor_task_assurance`, and provides the `anchor` command. ActionGate installs/imports/runs as `actiongate`. Update client imports to the current Anchor namespace; no retired import alias is shipped. New study manifests use `full_anchor_verifier_jobs` with `anchor-synthetic-study-0.2.2`. Prepare fresh studies rather than mixing earlier artifacts. New receipts use `anchor-reference-controls-0.2.2`; checksum verification remains a structural check, not issuer authentication.
