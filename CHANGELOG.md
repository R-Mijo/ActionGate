# Changelog

## 0.3.0 — 5 November 2026

- Introduced Meeho ActionGate as a separate project built on the evidence-checking foundation. Anchor Task Assurance retains the original project history.
- Added a separate scoped action broker with full default-argument binding, single-use tickets, expiry, owner revocation and concurrent replay protection.
- Added host-clock review sessions, explicit reviewer/issue checks, four autonomy levels and sliding-window circuit breaking.
- Added pre-call usage reservations, attempt limits, actual usage settlement and explicit context bundles.
- Added packaging, included study data, and Windows/Linux installation checks.
- Preserved the existing evidence gate and independent study tools instead of replacing them with simulated accuracy claims.

## 0.2.0 — 29 October 2026

First runnable reference release derived from Marco A.'s AGP version 0.1 proposal.

- Replaced disconnected starter fragments with a coherent standard-library Python gate and tests.
- Corrected the total-14 assurance boundary and added provisional minimum assurance floors.
- Required complete typed checks, material claims, approved applicable sources, and valid locators.
- Separated release of a preliminary recommendation from authority to approve or pay an expense.
- Added canonical receipt checksums with explicit authenticity limitations.
- Revised the synthetic expense policy and all 30 gold cases before any model comparison.
- Gave all primary comparison conditions the same evidence and output contract.
- Added randomized prompt preparation, response screening, and separate verifier packets.
- Replaced unsupported novelty and commercial certainty with sourced related work and testable hypotheses.

This release has software verification only. Independent LLM effectiveness and production validation remain pending.
